# Code of Conduct

This is a small project run by one person. The rules are short:

- Be civil. Disagree about code, not about people.
- Don't harass anyone. Don't post anyone's private info.
- Assume good faith. Most disputes are misunderstandings.

If someone's making the project worse to be around — for you or anyone
else — email <conduct@refrax.website>. I'll look at it.

If I ask you to stop something and you don't, I'll block you. There's
no formal process beyond that; I'm one person.
